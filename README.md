# aiot-mission

AIoT 국제전시회 2026 참관 미션 웹앱. 교장 5기(2026. 11. 5.(목) 13:00~15:00, 코엑스 3층 D홀). `aifesta-mission`과 같은 구조이며 디자인은 네이버 톤(흰 바탕, NAVER Green `#03C75A`, 시스템 폰트)이다.

- 14개 구역 스탬프. AIoT 국제전시회 8분야(산업·생활안전·재해재난 / 스마트 홈·오피스·헬스케어 / 스마트 시티·빌리지 / 에너지·환경 / 제조·유통·물류·농수축산 / S/W·플랫폼 / 디바이스·통신기기 / 보안), AI EXPO MARS 2026 5분야(Moving City AI / AX & Physical AI / Real Life AI / Sustainable City AI / X-Space AI), AI&IoT 쇼케이스 NIPA 전시관(A120). 공식 전시품목 분류와 MARSX 분류를 그대로 쓴 것으로, 특별관 단위가 아니다
- 분야별 기록: 방문 부스(발표된 기업 칩 + 직접 추가 입력), 학교 적용가능성 상·중·하(선택), 교장용 질문 1개 메모
- 마무리 문항 3개(적용해보고 싶은 기술 1가지 이상, 교직원에게 한 문장, 1년 내 들어올 기술·이유) → 성명·소속교로 제출
- 같은 기기에서 다시 제출하면 시트의 기존 행을 덮어쓴다(제출ID 기준)
- 모든 입력은 기기(localStorage)에 즉시 저장되어 통신 두절·이탈 후에도 복구된다
- 제출 완료 화면에 집결 안내(14:50 D홀 출구, 15:00 버스 출발), 제출 후 하단 버튼은 「수정해서 다시 제출」
- 카카오톡 안에서 열면 기록 전에는 기본 브라우저로 자동 전환(`kakaotalk://web/openExternal`), 기록이 있으면 안내만 표시

## 반영 상태와 남은 것

- 2026 AIoT Week Korea 브로슈어(2026-10-12 제작)를 반영했다. AI EXPO MARS 2026은 화성특례시가 주관하는 별도 전시로, 같은 D홀에서 11. 3.~5. 함께 열린다. 쇼케이스는 NIPA 전시관(A120)에 중소기업 8곳이 모인다.
- 부스 번호가 확인된 곳은 A120뿐이다. 다른 기업은 브로슈어·보도자료로 참가만 확인되어 번호 없이 올렸다.
- 공식 부스 배치도와 참가사 리스트(`booth2026.pdf`, 기업명 가나다순 + 부스 번호)는 안내 상자에서 공식 페이지로 연결해 둔 상태다. 이 PDF를 받아 반영하면 아래를 채운다.
  1. `MAP.img`에 배치도 이미지 파일명, `MAP.alt`에 설명, `MAP.pending`은 빈 문자열
  2. `HALLS[].b`를 `"D113 기업명 · 제품"` 형식으로 교체(번호가 앞에 오면 목록에서 굵게 나온다)
  3. `HALLS[].loc`에 분야별 위치 힌트, `ROUTE`에 입구→출구 순서(HALLS 순번, 0부터)
- 11. 5.(목)에는 D홀 세미나장에서 OCEAN Summit 2026(사전등록 행사, 10:00~15:20)이 열린다. 미션 대상이 아니라 앱에는 넣지 않았다. 신제품·솔루션 발표회와 국제 컨퍼런스는 11. 3.·4.에만 있다.

## 배포

1. 구글 시트 「AIoT 참관미션 제출」을 새로 만들고 `확장 프로그램 → Apps Script`에 `Code.gs`를 붙여넣는다. AI FESTA 시트와 섞이지 않도록 별도 시트를 쓴다.
2. 편집기에서 `setup` 함수를 한 번 실행한다 → `제출`·`현황`·`명단` 탭 생성.
3. `배포 → 새 배포 → 웹 앱`, 실행 사용자 **나**, 액세스 **모든 사용자**. 코드 수정 시에는 `배포 관리 → 편집 → 새 버전`(URL 유지).
4. 발급된 `…/exec` URL을 `index.html`의 `API_URL`에 넣는다. 연결되어 있다.
5. Vercel에서 이 저장소를 Import(프레임워크 Other, 빌드 없음) → `aiot-mission.vercel.app`.

## 수정 지점 (`index.html` `<script>` 상단)

- `API_URL` — Apps Script 배포 URL
- `INFO` — 연수명, 기수, 일자, 장소, 관람 시간, 집결 지점, 버스 시각
- `CONTACTS` — 인솔자·사무국 연락처. 안내 상자와 제출 완료 화면에 전화·링크 버튼으로 나온다
- `MAP` — 배치도 이미지, 공식 페이지 링크, 브로슈어 PDF, 안내문
- `HALLS` — 전시 분야. `g`는 묶음(0 AIoT 국제전시회, 1 AI EXPO MARS, 2 쇼케이스), `z`는 카드 배지 코드, `loc`는 위치 힌트, `b`는 부스 칩 목록, `q`는 교장용 질문
- `ROUTE`·`ENTRY`·`EXIT`·`ROUTE_NOTE` — 추천 동선
- `FIELDS` — 시트 열 [키, 머리행 이름]
